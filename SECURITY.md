# Segurança

Reporte vulnerabilidades em particular pela opção **Report a vulnerability**
na aba Security deste repositório. Inclua passos para reproduzir o problema e o
impacto observado. Evite publicar detalhes exploráveis antes de uma correção.

Nunca publique credenciais em issues. Segredos de produção pertencem às
variáveis de ambiente dos provedores, e tokens de ativação devem permanecer fora
de query strings e logs.
